# WordPress-версия «Хроники преображения Мира»

В репозитории хранится только собственный код проекта:

- `wp-content/themes/hroniki-mira` — тема сайта;
- `wp-content/plugins/hroniki-core` — книги, загрузка файлов и настройки;
- `import/import-content.php` — повторяемый импорт восстановленного архива;
- `import/restore-article-branding.php` — точечное восстановление названия «Вестники Перемен» в материалах без перезаписи текущего контента;
- `import/import-book-files.php` — повторяемая загрузка актуальных PDF со второго сайта и привязка к книгам;
- `.htaccess` — правила постоянных ссылок и базовая защита.

Ядро WordPress и пользовательские загрузки намеренно не включены в Git. На сервере архив старого сайта подключён по адресу `/archive/`, а новые файлы загружаются штатно в `wp-content/uploads`.

Название WordPress-сайта, шапки и футера — «Хроники преображения Мира». Исторические статьи, книги и названия движения сохраняют исходную формулировку «Вестники Перемен».
